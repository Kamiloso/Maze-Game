# Maze-Game
 A console game written in C++ for Windows, where you explore the procedurally generated maze, fight enemies and try to achieve the highest score possible. Enjoy different enemy spawning phases. How far can you get?

## Opening project

### Prerequisites
- Visual Studio 2022 (Platform Toolset v143)  
- C++14

### Steps
- Download project as a `.zip` file.
- Unpack everything.
- Open `.sln` file with Visual Studio.

### How to run
- Ensure that you are in `Release` (not `Debug`) mode.
- Compile and run by pressing `Ctrl + F5`.
